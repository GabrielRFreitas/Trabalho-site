## 2. Tema e objetivo

O Explore Brasil é um site informativo sobre turismo no Brasil. Seu objetivo é apresentar sugestões de destinos, roteiros e dicas para organizar viagens, utilizando os recursos de HTML e CSS estudados na disciplina. O projeto não realiza vendas ou reservas.

## 3. Tecnologias e organização

O site utiliza HTML para estruturar o conteúdo e CSS para definir cores, tipografia, espaçamento e adaptação à largura da tela. As cinco páginas compartilham o arquivo `style.css` e o mesmo menu de navegação. As três fotografias são armazenadas na pasta `imagens/`.

O HTML inclui a definição do idioma português do Brasil, textos alternativos nas imagens, rótulos nos campos do formulário e um link para pular diretamente ao conteúdo. O CSS organiza os conteúdos em uma coluna em telas menores e destaca o foco durante a navegação pelo teclado.

## 4. Finalidade das páginas

| Página | Arquivo | Finalidade |
| --- | --- | --- |
| Início | index.html | Apresentar o site, destacar estilos de viagem e encaminhar o visitante para Destinos e Roteiros. |
| Destinos | destinos.html | Exibir Florianópolis, Porto de Galinhas, Gramado, Campos do Jordão, Bonito e Chapada dos Veadeiros, agrupados em praia, serra e natureza. |
| Roteiros | roteiros.html | Oferecer sugestões de três dias para praia e serra e de cinco dias para natureza, com links para destinos e dicas. |
| Dicas | dicas.html | Reunir orientações sobre planejamento, bagagem, passeios e cuidado com os locais visitados. |
| Contato | contato.html | Demonstrar um formulário com nome, e-mail, destino de interesse e mensagem. |

O formulário utiliza a validação nativa do navegador para os campos obrigatórios e o formato do e-mail. Quando preenchido com dados válidos, recarrega a página e abre o aviso explicativo. Não existe processamento de mensagens pelo projeto; os dados de teste aparecem na URL.
